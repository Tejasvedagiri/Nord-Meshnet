# Security policy

Please report vulnerabilities privately through GitHub's
**Security → Report a vulnerability** on this repository. Do not open a
public issue.

Include the image tag (or digest), what you observed, and steps to
reproduce. You should get an acknowledgement within 7 days.

In scope: the `nordmesh-init` binary, the Dockerfile, and the workflows in
this repository. Vulnerabilities in the NordVPN client itself should go to
Nord Security (https://nordsecurity.com/security); we will bump the pinned
client once a fix ships.

Supported versions: the latest minor release.
